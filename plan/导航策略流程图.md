# 当前导航策略流程图（代码实测版，2026-11-12 22:50）

> 依据：`lite2_sim/run_mujoco.py`、`mujoco_navigation.py`、`navigation_core/{session,planner,control,course,terrain,grid}.py` 与 `config/ruins_reference.json`。
> 运行期参数来自 `run_navigation()` 默认值 + `config.mujoco_navigation` 覆盖。

## 0. 总览：五层结构

```
任务/课程层 (CourseSession)
   └─ 全局层 (plan_grid: A* / 前沿探索 / 管口轴线引导)
        └─ 控制层 (NavigationController: 纯跟踪 → v, ω)
             └─ 局部执行层 (_local_rollout: 速度采样 + 2.5D/脚印安全检查 + 打分)
                  └─ 执行器层 (MujocoVelocityExecutor: 延迟/加减速/打滑 → mocap 夹具)
```

## 2. 全局规划层决策树（plan_grid）

```
开始
 ├─ 起点出图 / 起点非空闲 → start_out_of_map / insufficient_observations
 ├─ 起点在膨胀区或占据 → start_blocked        ─┐
 ├─ 目标出图 / 目标在膨胀区或占据 → goal_blocked ├─ 可恢复状态（有界恢复）
 ├─ 目标已知空闲且 A* 可达 ──────────────→ path_found（含平滑）
 ├─ guided_corridor 开启且 A* 退化为探索/受阻 → 轴线直行 path_found（局部安全检查兜底）
 └─ 否则 → 可达前沿探索：
        可达代价图 → 前沿带（+frontier_radius 膨胀）→ 访问惩罚 + 后方惩罚
        → exploring（选择前沿）；无前沿 → no_reachable_known_free_frontier
```

## 3. 恢复状态机（_recover，有界）

```
stalled / start_blocked / goal_blocked / map_disconnected / insufficient_observations
        │
        ▼
  尝试 #1：原地转 1.2 s（±0.24 rad/s）→ 后退 0.8 s（≤0.08 m/s）→ 静置 0.5 s
        │  失败前沿标记 visited（权重 2），重规划
        ▼
  仍失败 → 尝试 #2、#3（上限 recovery_attempt_limit=3）
        │
        ├─ 成功（状态回到 navigating/exploring/…）→ 记录 recovery_succeeded
        └─ 3 次用完 → recovery_exhausted → 终态（goal_blocked/stalled/…）
  纯探索模式：永不耗尽，交给 navigation_timeout（1200 s）
```

## 4. 课程层（--course）

```
CourseSession.tick()
 ├─ 段超时（course.timeout_s 均分/段配置）→ stage_failed(timeout)
 ├─ navigation.tick() → 命令 + 恢复事件转发
 ├─ status != goal_reached → 继续
 ├─ 真值/估计位姿是否在检查点区域内 → 否则 stalled
 ├─ 检查点停留 settling_stop_s
 ├─ probe 检查点（dead_end / reject）：
 │    停止并转向观测 → _observed_barrier() 用雷达点确认
 │    · 死胡同：近侧横向点 ≥4 → branch_closed
 │    · 窄口：实测净宽 < 0.44+2×0.08=0.60 m → passage_rejected
 │    未确认到 probe_timeout (4 s) → insufficient_observations
 ├─ checkpoint_reached → 下一个检查点 / stage_completed
 └─ 最后一段完成 → finished；CourseEvaluator 用真值独立判分
```
