## 导航层 RL 论文的边界裁定（用户明确要求「是导航，先不考虑步态」）

- **硬判据是策略的动作输出，不是论文标题**：输出关节目标/力矩/足端/落脚点 = L0 步态层（排除）；输出 `vx,vy,ω` / Twist = L1；输出路点、局部路径、路径条件规划 = L2；输出前沿/子目标/探索顺序/返航 = L3。L1–L3 才是本次清单范围。
- **官方 arXiv 页仲裁结论**（易错，勿再引用二手说法）：
  - `arXiv:2602.12724` 官方标题是 **TRAIN** 不是 TRANS（v4 改名）；含 TRAIN-Loco（L0）+ TRAIN-Nav（LiDAR→差速运动学 ego-actions，L1），只取 Nav 部分。
  - `arXiv:2604.26504` HiPAN 确实存在，Comments: `Accepted to RA-L 2026`；高层输出 planar velocity + body posture，摘要明确含 escape from local minima / narrow height-constrained spaces。
  - `arXiv:2506.05997` SRU 官方 Comments 仅 `22 pages`，**未写 IJRR**。
  - `arXiv:2509.23203` CE-Nav 官方 Comments 无 ICLR 2026，只有项目页 `https://ce-nav.github.io/` 与代码 `https://github.com/amap-cvlab/CE-Nav`；IL-then-RL。
  - `arXiv:2603.13888` Path-conditioned RL 官方摘要**未写** A* on PRM / Unitree B2W / dead ends，这些细节只能标「代理或项目页补充」。
  - `arXiv:2607.15036` VOP-Nav 官方 HTML 明确 `12-dimensional target joint positions` + PD 200 Hz → **L0，排除**；VOP-Net 的 safe velocity region 只是观测/奖励，不是动作输出。
- **关键工程判断**：线上 `go2-agent-v1` 的 `actions [B,12]` 本身就是关节目标，属于 L0。因此导航层 RL 论文**不能直接套到线上 ONNX 策略训练**；它们只能用于线下 Lite2 的 `/cmd_vel` 高层、Webots 导航层，或作为任务语义/状态机级别的迁移依据。这与「不做权重级 Sim2Real」的既有决策一致。
